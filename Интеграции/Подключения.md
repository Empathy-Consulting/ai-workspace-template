# 🔗 Мои интеграции

Здесь ты можешь подключить свои сервисы для автоматизаций.

---

## Как подключить сервис

1. Напиши в чат: **"Подключи [название сервиса]"**
2. Перейди по ссылке которую даст агент
3. Войди в свой аккаунт и разреши доступ
4. Готово!
