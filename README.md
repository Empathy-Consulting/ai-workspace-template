# 👋 Добро пожаловать в AI Workspace

Это твое рабочее пространство для создания автоматизаций с помощью AI.

---

## 🚀 Быстрый старт

### Шаг 1: Подключи сервисы

Открой папку **Интеграции/** и следуй инструкциям для подключения:
- Gmail
- Slack  
- Notion
- И других сервисов

### Шаг 2: Опиши свой процесс

Создай файл в папке **Процессы/** и опиши:
- Что запускает процесс (триггер)
- Какие действия нужно выполнить
- Какой результат ожидается

### Шаг 3: Попроси агента помочь

Открой чат (панель снизу) и напиши:

> "Помоги создать автоматизацию для процесса [название]"

---

## 📁 Структура папок

| Папка | Описание |
|-------|----------|
| **Процессы/** | Описания твоих бизнес-процессов |
| **Автоматизации/** | Созданные автоматизации и их статус |
| **Интеграции/** | Подключение сервисов |

---

## 💬 Примеры запросов к агенту

- "Когда приходит письмо от клиента - создай задачу в Notion"
- "Каждый понедельник отправляй отчет в Slack"
- "Если в форме указан VIP клиент - уведоми менеджера"
- "Синхронизируй контакты из HubSpot в Google Sheets"

---

## ❓ Нужна помощь?

Просто напиши в чат: **"Помоги"** - и агент подскажет следующие шаги.
