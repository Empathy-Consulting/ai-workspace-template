# Workflow: Создание автоматизации

## Обзор

Этот workflow помогает пользователю создать автоматизацию через диалог.

---

## Шаги

### 1. Понять задачу

**Вопросы:**
- Что ты хочешь автоматизировать?
- Есть ли описание процесса в папке Процессы/?

**Действия:**
- Если есть файл процесса - прочитать его
- Если нет - помочь создать описание

---

### 2. Определить триггер

**Вопросы:**
- Что запускает процесс?
  - Новое письмо?
  - Определенное время?
  - Событие в сервисе?
  - Заполнение формы?

**Результат:**
- Тип триггера
- Условия срабатывания

---

### 3. Определить действия

**Вопросы:**
- Что нужно сделать когда сработает триггер?
- Нужны ли условия (если X то Y)?
- В каком порядке выполнять?

**Результат:**
- Список действий
- Условия (если есть)
- Порядок выполнения

---

### 4. Проверить интеграции

**Действия:**
- Проверить какие сервисы нужны
- Проверить какие уже подключены
- Помочь подключить недостающие

**Скрипт:**
```bash
python backend/composio_helper.py check gmail
python backend/composio_helper.py check notion
python backend/composio_helper.py check slack
```

---

### 5. Подтвердить план

**Показать пользователю:**
```
Вот что я сделаю:

Триггер: [описание]
Действия:
1. [действие 1]
2. [действие 2]
3. [действие 3]

Нужны сервисы: Gmail ✅, Notion ✅, Slack ⚪

Все верно?
```

---

### 6. Создать автоматизацию

**Действия:**
1. Сгенерировать n8n workflow
2. Создать документацию в Автоматизации/
3. Активировать (если все сервисы подключены)

**Скрипт:**
```python
from backend.workflow_generator import *

workflow = generate_email_to_notion_workflow(
    workflow_name="[Название]",
    email_filter="[Фильтр]",
    slack_channel="[Канал]"
)
save_workflow(workflow, "[filename]")
```

---

### 7. Подтвердить результат

**Сообщить пользователю:**
```
✅ Автоматизация "[Название]" создана!

Файл: Автоматизации/[Название].md
Статус: Активна / Ожидает подключения [сервис]

Хочешь протестировать?
```

---

## Типичные сценарии

### Email → Notion + Slack
- Триггер: Gmail
- Действия: Notion (создать), Slack (уведомить)

### Расписание → Отчет
- Триггер: Schedule
- Действия: Sheets (прочитать), Slack (отправить)

### Форма → CRM
- Триггер: Webhook/Form
- Действия: HubSpot (создать контакт), Email (отправить)

---

## Обработка ошибок

### Сервис не подключен
```
Для этой автоматизации нужен [сервис].
Давай подключим? [Ссылка]
```

### Недостаточно информации
```
Мне нужно уточнить:
- [Вопрос]
```

### Ошибка генерации
```
Упс, что-то пошло не так.
Давай попробуем еще раз. Расскажи подробнее о [часть процесса].
```
