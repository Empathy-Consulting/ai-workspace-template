# 🤖 Мои автоматизации

Здесь будут храниться все созданные автоматизации.

---

## Как это работает

1. Ты описываешь процесс в папке **Процессы/**
2. Просишь агента создать автоматизацию
3. Агент создает файл здесь с описанием и статусом
4. Автоматизация начинает работать!

---

## Мои автоматизации

_Пока нет активных автоматизаций_

Чтобы создать первую, напиши в чат:

> "Создай автоматизацию для процесса Обработка заявок"

---

## Статусы

| Иконка | Значение |
|--------|----------|
| ✅ | Работает |
| ⏸️ | На паузе |
| ❌ | Ошибка |
| 🔧 | Настраивается |

---

## Управление

Чтобы управлять автоматизацией, напиши в чат:

- **"Останови автоматизацию [название]"**
- **"Запусти автоматизацию [название]"**
- **"Покажи статистику [название]"**
- **"Удали автоматизацию [название]"**
